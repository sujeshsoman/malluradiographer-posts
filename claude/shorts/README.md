# Mallu Radiographer daily Shorts

Files used by the daily scheduled task that builds and publishes a YouTube Short on Mallu Radiographer at 4 PM UK.

- `rulebook.md`: how every Short is written (script, captions, title, description).
- `topic-bank.md`: starter topics, rotated by category.
- `sample-package.md`: a worked example of a package.
- `production-log.md`: one row per day. Change a row's Status to `Hold` to stop that Short going live.
- `packages/`: one package per Short, with build notes.
- `my-tips.md` (optional): add short tips from your own practice, one per line, and the task will use one per Short as "Sujesh's tip".

Everything else in this repo belongs to the Instagram task.
